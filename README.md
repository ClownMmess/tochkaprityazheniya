# Точка притяжения

Версия 1.3.1, обновление MAX_app_v1_3.zip. Персональная афиша и совместный выбор событий в MAX.

На Windows: запустите `start-demo.bat`, затем откройте http://localhost:8080.

Полная инструкция по обновлению без потери базы, использованию и размещению в MAX — [START_HERE_RU.md](START_HERE_RU.md).

Технологии: React + TypeScript, FastAPI, PostgreSQL, Docker Compose. Опциональный локальный поиск через Ollama. Клиент получает события из серверного каталога; секреты задаются в `.env`.
