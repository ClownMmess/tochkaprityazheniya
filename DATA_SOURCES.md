# Данные и права на использование

Состояние на 30.09.2026. Источники не названы партнёрами проекта: договорённости с ними отсутствуют.

| Группа | Что есть в MVP | Текущее подключение |
|---|---|---|
| KudaGo | Подготовленные снимки событий и мест, ссылка на оригинал | Документированный открытый API, обновление включено |
| KASSIR.RU | Ранее подготовленные записи каталога в seed | Сетевой адаптер удалён, API не используется |
| Nethouse, BASE, КРОП Арена, VK Stadium, StandUp Cafe, ВДНХ, Гараж | Снимки, ссылки и исходные адаптеры страниц | Отключены по умолчанию |
| Антикафе, ярмарки и местные площадки | Небольшие подготовленные подборки со ссылками | Отключены по умолчанию |
| Timepad | Опциональный адаптер документированного API | Без токена и разрешения не подключён |
| MAX | Авторизация, ссылки на подборки, личные уведомления | Нужны выданный токен, сервер и проверка в MAX |

Регламент трека разрешает подготовленные данные при явном раскрытии этого факта (с. 7, п. 10). Это не является разрешением правообладателя на перепубликацию любых материалов. Правовой статус сторонних снимков за пределами KudaGo требует подтверждения до публичного коммерческого использования и уточнения для конкурсной публикации. Не заявляйте 16 действующих интеграций: 16 — число источников в подготовленных данных.

KudaGo: https://docs.kudago.com/api/. Открытая лицензия требует прямой индексируемой ссылки на конкретный материал. Карточки и подробности сохраняют её. Не используйте название KudaGo как собственный бренд, не продавайте исходный набор и не выдавайте его за принадлежащий команде. Реклама и права третьих лиц имеют отдельные ограничения.

Лицензии программных зависимостей: THIRD_PARTY_NOTICES.txt. Наличие открытой библиотеки не даёт прав на внешние данные. Изображения подгружаются по URL источников через ограниченный серверный прокси, не входят в исходный архив как чужие файлы.

Завершённые события исключаются из актуальной выдачи. У каждого материала хранится время получения, отличное от времени изменения у источника. Если источник недоступен, последний снимок сохраняется. О статусе попыток можно узнать через API sources и журналы catalog.
