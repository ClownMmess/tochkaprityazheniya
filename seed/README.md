# Резервные данные · 1.3.1 · 29.09.2026

При `init` снимки объединяются последовательно: `kudago_snapshot.json`, `venues_snapshot.json`, `extended_snapshot.json`, `local_snapshot.json`, `updates_snapshot.json`. Это нормализованные данные публичных источников, не синтетические события. Более свежая запись БД не заменяется старым снимком. Повторный импорт идемпотентен.

- Исходные KudaGo: 645 записей; площадки: 155 программ.
- Расширенный снимок 1.2: 7495 записей KASSIR, KudaGo Places, ВДНХ, «Гараж».
- Дополнение 1.3: 7166 записей — исправленная физическая география KASSIR, актуальные места KudaGo, новые антикафе, рынки/ярмарки и организаторы. Старые KASSIR-записи обновляются, а не добавляются как независимые копии.

Дополнение 1.3.1 содержит свежие данные KudaGo и Nethouse, включая бесплатные события Краснодара. Количество строк снимков нельзя складывать как количество карточек: более свежие данные заменяют записи того же источника, а завершённые события скрываются.

Неизвестные цена/возраст остаются неизвестными. У недатированных мест нет искусственных сеансов. Цена и билетная ссылка датированных событий сохраняются по отдельным сеансам. В исходных объектах есть ссылки на первоисточники и время получения; это не фиктивное время изменения источника.

Автообновление: отдельный Compose-сервис `catalog`, при запуске и каждые 6 часов. Ручной запуск: `python -m app.cli import-events`. Для событий действует горизонт шесть месяцев; места скрываются без повторной проверки спустя 30 дней.
