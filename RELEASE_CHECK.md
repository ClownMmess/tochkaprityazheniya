# Проверка сборки 1.3.2

Дата: 30.09.2026. Основа: MAX_app_v1_3_1_fixed.zip, исправленная ветка MAX_app_v1_3.zip. Это отчёт о выполненных проверках, а не сертификат допуска к конкурсу.

## Выполнено локально

- 30 проверок API: каталог и пагинация, бесплатные события, предел бюджета, возраст, русский запрос, профиль, подборка до 5 событий, несколько голосов и отмена, скрытие результатов до выбора, проверка подписи MAX и отказ при изменении данных.
- TypeScript и production-сборка Vite завершились без ошибок.
- В Chromium проверены интерфейс голосования и ширина 390 px: горизонтального переполнения и ошибок JavaScript не обнаружено.
- С нуля выполнены миграции SQLite и штатная загрузка всех подготовленных снимков.
- Проверен синтаксис Python и shell-скриптов; скрипт подготовки сдачи проверен на временной копии.
- OpenAPI 3.1 содержит схемы ответов основных маршрутов. Подготовлены 22 сценария DATA-API и данные для проверки.
- В поставку не включены секреты, локальные базы, журналы, node_modules, промежуточные сборки и внутренние проверочные сценарии.

## Требует реального размещения и действий команды

1. Поднять production в Docker с PostgreSQL. Здесь Docker недоступен; работу контейнеров и укладывание холодной сборки в 5 минут подтвердить нельзя. Для замера есть scripts/measure-build.py.
2. Подключить публичный HTTPS URL к выданному боту, проверить сценарий двумя аккаунтами в мобильном и веб-клиентах MAX. Проверка HMAC локально не заменяет эту проверку.
3. Проверить доставку сообщений и напоминаний от бота, а также обновление KudaGo на сервере.
4. Подтвердить условия использования сторонних подготовленных снимков либо убрать неподтверждённые записи из передаваемой версии. Данные и ограничения раскрыты в DATA_SOURCES.md. 16 источников снимка не означают 16 действующих интеграций.
5. Заполнить реальные URL, сведения о команде и доступы для жюри; после этого заморозить версию и посчитать итоговый SHA-256.

## Что изменилось относительно 1.3.1

- Исправлен сброс раннего поискового запроса при загрузке профиля: поле, фильтры и быстрые сценарии ожидают завершения входа. Проверено в браузере с искусственной задержкой авторизации.

- Добавлены контракты ответов API, security-схемы OpenAPI и обязательные материалы сдачи.
- Удалён загрузчик недокументированного API KASSIR. Автообновление по умолчанию ограничено документированным открытым API KudaGo.
- Добавлены пошаговое размещение, безопасный ввод токена, установка Docker, замер сборки и заполнение метаданных сдачи.
- Собраны сведения о лицензиях зависимостей. Внешняя LLM по умолчанию не нужна.
- Визуальный стиль MVP сохранён. Новые скриншоты получены из работающей локальной сборки 1.3.2.
