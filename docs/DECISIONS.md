# Решения версии 1.1 — 29.09.2026

1. Девять новых замечаний пользователя расширяют прежний P0: разрешены дополнительные источники и выбор до пяти событий. Остальные приоритетные поправки Ани сохраняются. Дизайн и стек сохранены.
2. Таблицы остаются нормализованными; новые источники/жанры — строки справочников и M2M. Исполнитель ищется по публичному названию/описанию, не подменяет организатора.
3. Явные условия запроса проверяются детерминированно и защищают результат от ошибок LLM. «Или» объединяет категории. Два человека и общий бюджет дают лимит на человека. Для нескольких категорий выдача чередует варианты.
4. По умолчанию известная минимальная цена сравнивается с бюджетом; strict требует известного верхнего предела. Наличие конкретного билета, мест и льгот не обещается. Бесплатность берётся из явного признака источника.
5. Одна карточка на событие; точные повторения названия/города/площадки скрываются из каталога без удаления исходных объектов. Все старые ID и связи сохраняются. Конкретные будущие сеансы выше постоянных программ.
6. Источники: KudaGo API, публичные афиши BASE, VK Stadium, КРОП Арена, StandUp Cafe. Timepad API возвращает 403; запрет не обходится, выдуманные записи не добавляются. Журнал импорта сохраняет ошибки по источникам.
7. Афиша в браузере приходит через серверный кеш только с разрешённых доменов. При ошибке загрузки показывается название и категория события, без случайной общей фотографии.
8. Групповой выбор: 2–5 разных событий, один изменяемый голос. Старые выборы из трёх работают.
9. Обновлённый снимок объединяется с существующей БД при запуске; более новые записи не перезаписываются старым снимком. Никакого удаления профилей или голосов. Фоновое расписание импорта настраивается командой отдельно.
10. Живой MAX, права бота, внешний HTTPS, Ollama и Docker Compose с PostgreSQL 16 требуют проверки на стенде команды. Локальные браузерные сценарии выполняются с настоящими API, БД и worker, без доставки в MAX.
