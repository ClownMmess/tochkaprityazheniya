# Чек-лист приёмки

Автоматически пройденные сценарии подробно перечислены в TECHLEAD_REPORT.md. Для компьютера команды:

- [ ] Чистый Docker Compose запускается и /health возвращает database=ok.
- [ ] После stop/start сохраняются профили, tracking и голоса.
- [ ] Источник, дата получения, неизвестные поля и пометка тестовых записей видны.
- [ ] Москва/Краснодар, дата, категория, цена и возраст фильтруют ожидаемые записи.
- [ ] Нет результатов → предлагаемое ослабление даёт >0 и сохраняет остальные условия.
- [ ] MAX HMAC-вход работает на двух аккаунтах; веб вне MAX не выдаёт себя за них.
- [ ] Глубокая ссылка открывает нужный выбор; второй пользователь видит свой голос.
- [ ] Смена голоса не создаёт второй голос; ничья разрешается устойчиво.
- [ ] Настоящее подтверждение бота доставлено; отменённое напоминание не отправляется.
- [ ] Ссылка группы появляется после tracking; вступление добровольное.
- [ ] Модератор игнорирует неизвестную группу, не удаляет обычное несогласие правилом спама.
- [ ] В журнале модерации нет текста сообщения; повторный webhook не повторяет действие.
- [ ] При выключенной Ollama каталог работает, fallback/review обозначены честно.
- [ ] На мобильном и в веб-клиенте MAX нет критических ошибок/переполнения.
- [ ] Публичный стенд использует DEMO_MODE=false; тестовые JWT недействительны.
- [ ] Три репетиции завершены; резервное видео записано.


Дополнительно для версии 1.1: открыть `/mobile-preview.html`; проверить исходные три запроса, список источников, 25 категорий и 20 жанров, 18 подсказок с вводом в строку, пять событий в выборе, madk1d и Boulevard Depo. После обновления прежней установки проверить сохранённые профили/голоса и новый каталог. Timepad 403 должен оставаться видимым в журнале, а другие источники продолжать обновление.
