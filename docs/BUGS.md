# Исправления и оставшиеся проверки

| Проблема | Окружение / воспроизведение | Ожидание и исправление | Проверка |
|---|---|---|---|
| API и БД отсутствовали в прежнем комплекте | Старый skeleton не давал пользовательский сценарий | Добавлены модели, миграция, импорт, маршруты и DB-store | 17 интеграционных + E2E |
| Категории UI передавались как UUID | Выбрать категорию каталога | Фильтр передаёт slug согласно API | Сборка и ручной просмотр кода |
| Ослабление могло терять часть намерения | Пустой запрос с несколькими условиями | В /search/intent передаётся полный изменённый intent | Интеграционный тест |
| Повтор позднего напоминания менял время на now | Повтор PUT спустя несколько минут | Существующее немедленное напоминание сохраняется | Интеграционный тест |
| После onboarding оставался нижний scroll | Сохранить длинную форму профиля | При смене экрана/страницы прокрутка начинается сверху | Браузерный прогон |
| Не загруженная картинка оставляла пустую обложку | Недоступный внешний image URL | Под изображением остаётся нейтральная обложка | Снимки браузера |
| Demo JWT переживал переключение режима | Войти локально, выключить DEMO_MODE | Проверка пользователя блокирует demo-сессию; worker отменяет demo-доставку | Интеграционный тест входа |
| Документация описывала недостающий backend | Старый README | Текущие документы переписаны, старые вынесены в history | Проверка комплекта |

Не подтверждены как баги, требуют внешнего стенда: права MAX, native Bridge, скорость живой модели, сеть Docker/Ollama, Quick Tunnel и нативные MAX-клиенты. Ограничения PGlite и отсутствие прогона Docker не скрыты: см. TECHLEAD_REPORT.md.
