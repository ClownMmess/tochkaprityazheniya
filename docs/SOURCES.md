# Источники 1.2.0

| Источник | Официальная страница / API |
|---|---|
| KudaGo | https://kudago.com/public-api/v1.4/ |
| KASSIR.RU | https://msk.kassir.ru/ / https://krd.kassir.ru/ |
| BASE | https://base-club.com/ |
| VK Stadium | https://vk-stadium.ru/ |
| КРОП Арена | https://arenahall.info/krd/ |
| StandUp Cafe | https://standupcafe.ru/events |
| ВДНХ | https://vdnh.ru/events/ |
| Музей «Гараж» | https://garagemca.org/ru/events |

KASSIR: публичный `/api/search`, используемый собственной афишей сайта, пагинация до конца или явный partial при ограничении. Даты ограничены шестью месяцами, города сверяются с площадкой. Жанры рэп, рок, джаз, классика и поп загружаются из соответствующих разделов источника. Одноимённые показы в одной площадке объединяются, цена и билетная ссылка сохраняются отдельно по сеансам.

Время KASSIR нормализуется как опубликованное локальное время афиши (Москва/Краснодар). В проверенном API строка содержала +00:00, но часы совпадали с публичной афишей и расписанием BASE без дополнительного сдвига на три часа. Контрольный пример — The Beatles Festival, 10.10.2026 17:00; зафиксирован в тесте источника. Это адаптация к наблюдаемому формату поставщика.

ВДНХ и Гараж: JSON, встроенный в общедоступные страницы. Код источника не исполняется. Это не полная лента отмен, поэтому такие обновления помечены partial и не удаляют отсутствующие на странице будущие события.

KudaGo: отдельные каталоги событий и мест. Закрытые места исключаются. Для места нет выдуманных сеансов, цен или возрастных ограничений. Время проверки означает успешное чтение источника, а не гарантию, что сам источник безошибочен.

Timepad — опциональный адаптер при наличии доступа и TIMEPAD_API_TOKEN; не считается подключённым источником без данных. Защиты и CAPTCHA не обходятся.

Автоматический импорт: `python -m app.integrations.sources.scheduler`, отдельный Compose-сервис catalog. Успех фиксируется транзакцией; при ошибке источника импорт остальных продолжается, старые данные сохраняются. Истёкшие даты скрываются. Полные выгрузки могут отключать отсутствующие записи только своего типа и источника. PostgreSQL advisory-lock предотвращает одновременную ручную и автоматическую загрузку.
