Скриншоты — docs/screenshots-v1.1. Для воспроизведения: `pytest`, `npm run build`, `npm test`, `npm run test:e2e`, `node scripts/revision-e2e.cjs`. В браузерных тестах API не подменяются; полный сценарий отключает внешний MAX SDK только в локальном demo-режиме. Тестовые пользователи явно названы Павел/Аня.

Среда подготовки не содержит Docker. PGlite использует PostgreSQL-движок в WASM и не заменяет запуск Compose с PostgreSQL 16, проверку сетевых прав и резервного копирования на компьютере команды. Живой MAX Bridge, настоящий токен, доставка сообщений, права бота и локальная Ollama в этом выпуске не проверялись. Инструкция их подключения сохранена в START_HERE_RU.md.

Данные афиш проверены по публичным API/страницам площадок; доступность каждого из 800 индивидуальных URL и каждого билета не заявляется. Исходные даты и неопределённость цен сохранены. Автоматический фоновый импорт настраивается отдельно командой import-events.
